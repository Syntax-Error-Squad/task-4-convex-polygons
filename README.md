## Условие задачи:
## Задание 4. Выпуклые многоугольники
Реализовать класс выпуклых многоугольников на плоскости.

1. Операции: пересечение, проверка на нахождение внутри, триангуляция.
2. Методы: площадь, периметр.
3. Проверка выпуклости при инициализации из списка вершин.

____
## Описание решения
____
- `Point` представляет точку на плоскости. Разность двух точек образует
  вектор, а сложение точки и вектора — новую точку.
- `Vector` поддерживает сложение, вычитание, умножение на число, скалярное
  произведение, вычисление длины и ориентированной компоненты векторного
  произведения по оси Z.
- `ConvexPolygon` хранит вершины как кортеж объектов `Point`. Вершины должны
  быть перечислены по часовой стрелке.
- Периметр вычисляется последовательным обходом сторон с замыканием последней
  вершины на первую.
- Триангуляция выполняется проведением диагоналей из первой вершины.
- Площадь многоугольника равна сумме площадей полученных треугольников.
- Принадлежность точки проверяется по её положению относительно всех сторон.
- Пересечение строится последовательным отсечением по алгоритму
  Сазерленда — Ходжмана.

- При инициализации проверяется наличие как минимум трёх вершин.

| Класс или метод | Описание |
|---|---|
| `Point` | Точка с координатами `x` и `y` |
| `Vector` | Вектор на плоскости и операции над ним |
| `ConvexPolygon(vertices)` | Выпуклый многоугольник из последовательности вершин |
| `is_convex(vertices)` | Проверка возможности построения многоугольника |
| `perimeter()` | Вычисление периметра |
| `triangulate()` | Разбиение на треугольники |
| `area()` | Вычисление площади |
| `contains(point)` | Проверка нахождения точки внутри или на границе |
| `intersection(other)` | Пересечение двух выпуклых многоугольников |

## Установка виртуального окружения и запуск
____
### 1. Клонируйте репозиторий
```bash
git clone https://github.com/Syntax-Error-Squad/task-4-convex-polygons.git
cd task-4-convex-polygons
```
### 2. Создайте виртуальное окружение
```bash
python -m venv venv
```
### 3. Активируйте виртуальное окружение
- **Windows CMD**
```bash
.\venv\Scripts\activate
```
- **Windows PowerShell**
```powershell
.\venv\Scripts\Activate.ps1
```
- **macOS/Linux**
```bash
source venv/bin/activate
```
После активации виртуального окружения в командной строке появится префикс venv.
### 4. Запустите программу
