# Python lab 4

## Условие задачи

**Задание 4. Выпуклые многоугольники**

Реализовать класс выпуклых многоугольников на плоскости.

1. Операции: пересечение, проверка на нахождение внутри, триангуляция.
2. Методы: площадь, периметр.
3. Проверка выпуклости при инициализации из списка вершин.

## Описание решения

Решение состоит из трёх классов: `Point`, `Vector` и `ConvexPolygon`.

- `Point` представляет точку на плоскости. Разность двух точек образует
  вектор, а сложение точки и вектора даёт новую точку.
- `Vector` поддерживает сложение, вычитание, умножение на число, скалярное
  произведение, вычисление длины и ориентированной компоненты векторного
  произведения по оси Z.
- `ConvexPolygon` хранит вершины как кортеж объектов `Point`. Вершины должны
  быть перечислены **по часовой стрелке**.

### Проверка выпуклости

При создании многоугольника вершины проверяются статическим методом
`is_convex`. Многоугольник считается корректным, если:

- вершин не меньше трёх;
- во всех вершинах поворот идёт по часовой стрелке (векторное произведение
  соседних сторон неположительно);
- хотя бы один поворот ненулевой, то есть все точки не лежат на одной прямой;
- сумма углов поворота составляет ровно один оборот, что исключает
  самопересекающиеся фигуры вроде пятиконечной звезды.

Если хотя бы одно условие не выполнено, конструктор выбрасывает `ValueError`.

### Операции

- **Периметр** вычисляется последовательным обходом сторон с замыканием
  последней вершины на первую.
- **Триангуляция** выполняется проведением диагоналей из первой вершины:
  многоугольник с `n` вершинами разбивается на `n − 2` треугольника.
- **Площадь** равна сумме площадей треугольников, полученных при
  триангуляции. Площадь каждого треугольника считается через векторное
  произведение.
- **Принадлежность точки** проверяется по её положению относительно всех
  сторон. Точка на границе считается принадлежащей многоугольнику.
- **Пересечение** строится последовательным отсечением по алгоритму
  Сазерленда — Ходжмана. Если многоугольники не пересекаются или только
  касаются стороной или вершиной, возвращается `None`.

| Класс или метод | Описание |
|---|---|
| `Point(x, y)` | Точка с координатами `x` и `y` |
| `Vector(x, y)` | Вектор на плоскости и операции над ним |
| `ConvexPolygon(vertices)` | Выпуклый многоугольник из списка вершин, перечисленных по часовой стрелке |
| `is_convex(vertices)` | Проверка, что вершины задают невырожденный выпуклый многоугольник |
| `perimeter()` | Вычисление периметра |
| `triangulate()` | Разбиение на треугольники, возвращает список троек вершин |
| `area()` | Вычисление площади |
| `contains(point)` | Проверка нахождения точки внутри или на границе |
| `intersection(other)` | Пересечение двух выпуклых многоугольников или `None` |

## Пример использования

```python
from task_4_convex_polygons import Point, ConvexPolygon

square = ConvexPolygon([Point(0, 0), Point(0, 2), Point(2, 2), Point(2, 0)])
print(square.perimeter())               # 8.0
print(square.area())                    # 4.0
print(square.contains(Point(1, 1)))     # True
print(len(square.triangulate()))        # 2

other = ConvexPolygon([Point(1, 1), Point(1, 3), Point(3, 3), Point(3, 1)])
print(square.intersection(other).area())  # 1.0

far = ConvexPolygon([Point(5, 5), Point(5, 6), Point(6, 5)])
print(square.intersection(far))         # None

ConvexPolygon([Point(0, 0), Point(1, 1), Point(2, 2)])
# ValueError: Невозможно создать выпуклый многоугольник
```

## Установка и запуск

Проект использует только стандартную библиотеку Python, поэтому шаги 2 и 3
необязательны.

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/Syntax-Error-Squad/task-4-convex-polygons.git
cd task-4-convex-polygons
```

### 2. Создайте виртуальное окружение

```bash
python -m venv venv
```

На macOS и Linux команда может называться `python3`.

### 3. Активируйте виртуальное окружение

- **Windows CMD**

```cmd
.\venv\Scripts\activate
```

- **Windows PowerShell**

```powershell
.\venv\Scripts\Activate.ps1
```

- **macOS/Linux**

```bash
source venv/bin/activate
```

После активации в командной строке появится префикс `(venv)`.

### 4. Запустите программу

```bash
python task_4_convex_polygons.py
```
